# Wazuhroom v0.1.0

Concept: WazuhをつかったSOC業務の基本フローと操作方法を体験するコンテンツ / Experience the basic SOC workflow and operations using Wazuh.
Independent bilingual (ja/en) educational simulator. Browser-only offline single HTML, no runtime external dependencies or network. Wazuh 4.14 UI concepts; original implementation, no official logo or source copying. Advisory room, outside main room learning path, profile Other projects alongside hanabi.

## Module contract
`src/content.js`: UMD global `WazuhContent` and CommonJS. Exports `{version:'wazuhroom-1',referenceVersion:'4.14',cases:[...],agents:[...]}`. All authored prose `{ja,en}`. Invariant logs/field values remain English and identical in both languages. Each case:
- `id`, `stage` ('tutorial'|'guided'|'checklist'|'independent'), `title`, `brief`, `objectives` (array bilingual), `hints` (3 bilingual), `documents` [{id,title,body}], `agents` (array agent objects), `events` (array), `timeRange:{from,to}` ISO UTC strings, `answer:{verdict,priority,action,target,evidenceGroups:[id[]],documentIds:[id],facts,nextStep,explanation}` prose bilingual. Choice enums verdict incident/benign/unknown, priority high/medium/low, action escalate/monitor/verify. `target` existing agent.id. `steps` [{id,kind,title,body}] where kind 'events','range','search','detail','evidence','document','report'. No magic auto-complete on view: ops recorded by UI after actual user actions. Tutorial uses all 7. Other cases can use subset but always evidence/document/report. `evidenceGroups` AND of OR, max evidence group count + 2. Targets from agents.
- agent shape `{id,name,ip,status,os:{name,platform,version},lastKeepAlive}`. 3-5 agents per case.
- event shape `{id,timestamp,agent:{id,name,ip},rule:{id,level,description,groups,mitre?:{id:[],technique:[]}},decoder:{name},data:{...},full_log,syscheck?:{path,event,sha256_before?,sha256_after?}}`. Rule IDs either verified against official rules or custom 100001+ documented. Include collection conditions in docs. No invented attribution outside recorded fields. Events sorted chronological, unique stable IDs across dataset, 40-80 background events per case. Every critical finding has selectable event ID; docs can be required separately. Answer facts distinguish observed facts and limits.

`src/engine.js`: UMD global `WazuhEngine`, CommonJS, DOM-independent. Public exports:
- `get(object,dottedPath)`
- `search(events,{query:'',filters:[{field,value,negate:false,disabled:false}],from:'ISO',to:'ISO',module:'events'|'fim'})` => filtered array or throw Error. DQL documented subset: field:value, quoted phrase, numeric comparisons > >= < <=, AND OR NOT, parentheses, existence field:*, wildcard * for keyword fields. Typed mapping; unsupported syntax errors, no silent fallback. Unknown fields errors except known supported mapped fields absent in current case.
- `searchAgents(agents,query)` WQL subset fields id,name,ip,status,os.name,os.platform; = != ~ > < and/or parentheses. Unsupported/errors explicit.
- `createProgress(content)` => `{format:'wazuhroom-save',version:1,dataset:content.version,language:'ja',activeCaseId:content.cases[0].id,records:{[id]:{query:'',filters:[],from,to,view:'overview',evidence:[],documents:[],operations:[],report:{verdict:'',priority:'',action:'',target:'',facts:'',nextStep:''},completed:false,feedback:null,hint:0,expanded:null}}}`. language override UI.
- `assess(caseData,record)` => `{passed,checks:[{key,passed}],score}`. Require correct choices, selective evidence AND groups/budget, docs read, all case step kinds except report in operations (actual user action), facts and nextStep structural minimum length 10 (no semantics claimed). Completed flag only if all. Preserve completion on failed later draft? UI sets completed only upon pass and stores submission to allow validate. Engine should snapshot successful record as `completion` in UI, hydration validates snapshot rather than draft.
- `validateProgress(input,content)` => sanitized deep cloned valid progress or throw. Enforce allowed IDs, limits, filter shape, strings, enum report values, active case, no prototype keys; recompute completion via completion snapshot or record. No trusted imported score/status. Imported invalid leaves UI untouched.

Root owns UI/CSS/build/docs. Other agents own content.js and engine.js with dedicated tests. All filenames no external packages except optional jsdom development tests. Node built-in tests. Distribution `wazuhroom.html`, `docs/index.html`, `docs/wazuhroom.html` all identical. Language switching preserves query/report/current UI state and completion, initial ja if navigator primary language starts ja else en. Auto-save own key; JSON export/import with backup and confirmation; file:// no external loads. Accessibility semantic controls, visible focus, reduced motion. Tutorial guide panel separate from Wazuh-style application area.
